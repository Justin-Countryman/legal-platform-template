**License:** SIL OFL 1.1  
**Designer:** Claus Eggers Sørensen  
**Google Fonts:** https://fonts.google.com/specimen/Playfair+Display

Used in preset: **1 — Classical Authority** (heading)

## Files required

| File | Weight | Style |
|------|--------|-------|
| PlayfairDisplay-Regular.woff2 | 400 | normal |
| PlayfairDisplay-Bold.woff2 | 700 | normal |
| PlayfairDisplay-Italic.woff2 | 400 | italic |

## Download instructions

1. Visit https://fonts.google.com/specimen/Playfair+Display
2. Click **Get font** → **Download all**
3. Unzip — locate the `static/` folder
4. Convert or locate the `.woff2` files for the weights above
5. Rename to match the filenames in the table and place here

> Variable font available as `PlayfairDisplay-VariableFont_wght.ttf` —
> convert to woff2 with `woff2_compress` if preferred over static files.
