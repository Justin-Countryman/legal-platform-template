# Cormorant Garamond

**License:** SIL OFL 1.1  
**Designer:** Christian Thalmann  
**Google Fonts:** https://fonts.google.com/specimen/Cormorant+Garamond

Used in preset: **3 — Refined Practice** (heading)

## Files required

| File | Weight | Style |
|------|--------|-------|
| CormorantGaramond-Regular.woff2 | 400 | normal |
| CormorantGaramond-SemiBold.woff2 | 600 | normal |
| CormorantGaramond-Italic.woff2 | 400 | italic |

## Download instructions

1. Visit https://fonts.google.com/specimen/Cormorant+Garamond
2. Click **Get font** → **Download all**
3. Unzip — locate the `static/` folder
4. Copy the `.woff2` files for Regular, SemiBold, and Italic
5. Rename to match the filenames above and place here

> Cormorant Garamond is a display serif — render it large (2rem+) for best results.
> SemiBold (600) is used rather than Bold (700) for a more refined heading weight.
