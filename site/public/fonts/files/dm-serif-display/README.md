**Google Fonts:** https://fonts.google.com/specimen/DM+Serif+Display

Used in preset: **2 — Modern Counsel** (heading)

## Files required

| File | Weight | Style |
|------|--------|-------|
| DMSerifDisplay-Regular.woff2 | 400 | normal |
| DMSerifDisplay-Italic.woff2 | 400 | italic |

## Download instructions

1. Visit https://fonts.google.com/specimen/DM+Serif+Display
2. Click **Get font** → **Download all**
3. Unzip — copy the `.woff2` files
4. Rename to match the filenames above and place here

> DM Serif Display is a display-weight serif — only Regular (400) is available.
> Bold headings are achieved via CSS `font-weight: 700` which the browser synthesises,
> or by using the CSS variable `--heading-weight` at display sizes.
