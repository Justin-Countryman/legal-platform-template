## How this folder is kept

This family is **static**: one file, one weight, the latin subset as Google Fonts serves it (Phase 17C session 2b, `[R-539]`: chosen by eye over Barlow Condensed on real pages). The heading asks for this one weight; headings never synthesize a bold (`font-synthesis-weight: none`).
