# Libre Baskerville

**License:** SIL OFL 1.1  
**Designer:** Impallari Type (Pablo Impallari, Rodrigo Fuenzalida)  
**Google Fonts:** https://fonts.google.com/specimen/Libre+Baskerville

Used in presets: **5 — Corporate Clarity** (heading), **12 — Traditional Fallback** (heading)

## Files required

| File | Weight | Style |
|------|--------|-------|
| LibreBaskerville-Regular.woff2 | 400 | normal |
| LibreBaskerville-Bold.woff2 | 700 | normal |
| LibreBaskerville-Italic.woff2 | 400 | italic |

## Download instructions

1. Visit https://fonts.google.com/specimen/Libre+Baskerville
2. Click **Get font** → **Download all**
3. Unzip — copy the `.woff2` files
4. Rename to match the filenames above and place here

> Libre Baskerville is a static (non-variable) font. Only three cuts are
> available: Regular, Bold, and Italic. It has higher x-height and looser
> spacing than traditional Baskerville, optimised for on-screen reading.
