# Lato

**License:** SIL OFL 1.1  
**Designer:** Łukasz Dziedzic  
**Google Fonts:** https://fonts.google.com/specimen/Lato

Used in presets: **7 — Geometric Precision** (body), **12 — Traditional Fallback** (body)

## Files required

| File | Weight | Style |
|------|--------|-------|
| Lato-Regular.woff2 | 400 | normal |
| Lato-Bold.woff2 | 700 | normal |
| Lato-Italic.woff2 | 400 | italic |
| Lato-BoldItalic.woff2 | 700 | italic |

## Download instructions

1. Visit https://fonts.google.com/specimen/Lato
2. Click **Get font** → **Download all**
3. Unzip — copy the `.woff2` static files
4. Rename to match the filenames above and place here

> Lato is a static (non-variable) font. It has semi-rounded details
> that give it a warm yet stable character. One of the most widely used
> web fonts globally with proven on-screen readability.
