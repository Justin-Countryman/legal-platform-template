## Download instructions

1. Visit https://fonts.google.com/specimen/Proza+Libre
2. Click **Get font** → **Download all**
3. Unzip — copy the `.woff2` static files
4. Rename to match the filenames above and place here

> Proza Libre was designed to pair with larger display serifs. Its slightly
> humanist forms complement Cormorant Garamond's high-contrast elegance.
