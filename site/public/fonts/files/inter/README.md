# Inter

**License:** SIL OFL 1.1  
**Designer:** Rasmus Andersson  
**Google Fonts:** https://fonts.google.com/specimen/Inter

Used in presets: **4 — Editorial Authority** (body), **8 — Space Age Authority** (body)

## Files required

| File | Weight | Style |
|------|--------|-------|
| Inter-Regular.woff2 | 400 | normal |
| Inter-SemiBold.woff2 | 600 | normal |
| Inter-Bold.woff2 | 700 | normal |

## Download instructions

1. Visit https://fonts.google.com/specimen/Inter
2. Click **Get font** → **Download all**
3. Unzip — locate `static/` folder
4. Copy `.woff2` files for Regular, SemiBold, and Bold
5. Rename to match the filenames above and place here

> Inter was designed for screen readability at UI sizes. The variable font
> `Inter[wght].woff2` covers all weights from a single file — use it if
> bundle size is a concern (one network request vs. three).
