# DM Sans

**License:** SIL OFL 1.1  
**Designer:** Colophon Foundry  
**Google Fonts:** https://fonts.google.com/specimen/DM+Sans

Used in preset: **2 — Modern Counsel** (body)

## Files required

| File | Weight | Style |
|------|--------|-------|
| DMSans-Regular.woff2 | 400 | normal |
| DMSans-Medium.woff2 | 500 | normal |
| DMSans-Bold.woff2 | 700 | normal |
| DMSans-Italic.woff2 | 400 | italic |

## Download instructions

1. Visit https://fonts.google.com/specimen/DM+Sans
2. Click **Get font** → **Download all**
3. Unzip — locate the `static/` folder
4. Copy the `.woff2` files matching the weights above
5. Rename to match the filenames in the table and place here

> DM Sans is a variable font — `DMSans[opsz,wght].woff2` covers all weights.
> The static files in `static/` are provided for targeted weight loading.
