# Poppins

**License:** SIL OFL 1.1  
**Designer:** Indian Type Foundry, Jonny Pinhorn  
**Google Fonts:** https://fonts.google.com/specimen/Poppins

Used in preset: **14 — Modern Practice** (heading + body, mono-pair)

## Files required

| File | Weight | Style |
|------|--------|-------|
| Poppins-Regular.woff2 | 400 | normal |
| Poppins-SemiBold.woff2 | 600 | normal |
| Poppins-Bold.woff2 | 700 | normal |

## Download instructions

1. Visit https://fonts.google.com/specimen/Poppins
2. Click **Get font** → **Download all**
3. Unzip — locate `static/` folder
4. Copy `.woff2` files for Regular, SemiBold, and Bold
5. Rename to match the filenames above and place here

> Poppins ships as static weights only on Google Fonts (no variable woff2).
> Three separate files (~8 KB each at latin subset) cover the mono-pair.
