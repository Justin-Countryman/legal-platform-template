**Designer:** Florian Karsten  
**Google Fonts:** https://fonts.google.com/specimen/Space+Grotesk

Used in preset: **8 — Space Age Authority** (heading)

## Files required

| File | Weight | Style |
|------|--------|-------|
| SpaceGrotesk-Regular.woff2 | 400 | normal |
| SpaceGrotesk-Bold.woff2 | 700 | normal |

## Download instructions

1. Visit https://fonts.google.com/specimen/Space+Grotesk
2. Click **Get font** → **Download all**
3. Unzip — locate `static/` folder
4. Copy `.woff2` files for Regular and Bold
5. Rename to match the filenames above and place here

> Space Grotesk is a variable font — `SpaceGrotesk[wght].woff2` covers all
> weights from 300–700. No italic cut is available. Its quirky terminals and
> optical size compensation give it a distinctive technical character.
